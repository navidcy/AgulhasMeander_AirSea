# AgulhasMeander_AirSea

Jupyter notebooks for analyzing air–sea interactions around the Agulhas Meander, developed in support of the manuscript:

> Changing Southern Ocean meander drives multi-decadal atmospheric trends

by Amelie Meyer et al.

## What is in this repository

This repository contains notebook-based workflows for:

- computing 26-year mean fields
- computing 26-year trends and p-values
- analyzing meander crest/trough positions
- generating manuscript figures and tables

Key notebooks include:

- `mean_compute.ipynb` — computes 26-year mean SST and ERA5-based atmospheric fields
- `Cloud_trend_compute.ipynb` — computes total cloud cover trends and saves a derived NetCDF
- `CrestTroughPosition.ipynb` — analyzes crest/trough detections and positional changes through time
- `Fig1.ipynb`, `Fig2.ipynb`, `Fig3.ipynb`, `FigS1_and_S3.ipynb` — figure-generation notebooks
- `Tab1.ipynb` — extracts trend and p-value values at selected crest/trough locations

## Data and dependencies

The notebooks depend on external datasets that are **not included** in this repository, including:

- ERA5 reanalysis fields
- SST products
- MATLAB `.mat` meander files
- intermediate NetCDF outputs generated by other notebooks

They also use a scientific Python stack including:

- `numpy`
- `xarray`
- `scipy`
- `matplotlib`
- `seaborn`
- `cartopy`
- `cmocean`
- `pandas`
- `tqdm`
- `cosima_cookbook`
- `seawater`

## Running the notebooks

The notebooks use hard-coded filesystem paths such as `/g/data/...`, so they will need path updates before running in a different environment.

A typical workflow is:

1. generate mean or trend products
2. save derived NetCDF outputs
3. run figure/table notebooks that read those outputs

## Notes

This repository is organized as standalone notebooks rather than a packaged Python project. Reproducibility depends on access to the external data and the expected directory layout.
